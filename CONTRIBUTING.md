# Contributing to ML Eval Framework

Feedback on installation, data leakage, fairness calculations, ablation protocols and reproducibility is welcome. Please open an issue describing your Python version, expected behaviour, actual output and a minimal non-sensitive example.

For code changes: create a branch, add a focused regression test, run `python -m pytest tests/ -q` and submit a pull request. Do not commit credentials, proprietary datasets, patient data, local virtual environments or tracked experiment outputs. Report performance using reproducible commands and hold-out test data.

**Licence notice:** Repository visibility does not automatically authorise reuse. A top-level licence should be chosen and published by the maintainer before external redistribution under a named licence.
